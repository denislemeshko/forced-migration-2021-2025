# Вынужденная миграция: 2021–2025 — шаг 1

Учебный проект для GitHub. На этом шаге проверяем API и читаем небольшую выборку.

## Запуск

Нужен Python 3.11 или новее и доступ к api.unhcr.org. Дополнительные пакеты не нужны.
Из папки проекта выполните:

```sh
python check_api.py
```

Скрипт получает мировые итоги (5 строк), итоги по происхождению из Украины,
Сирии и Афганистана (15 строк), а также пару Украина → Германия (5 строк).
Сохраняет исходные JSON без изменений в data/raw и адреса запросов, время загрузки,
контрольные суммы и результаты проверок в checks.json. При ошибке завершится
с ненулевым кодом и запишет исключение в errors.log.
Одинаковый ответ сохраняется под тем же именем; изменённый — отдельным снимком.
Это проверочный скрипт, а не законченный пайплайн: автоматические повторы,
расписание, PostgreSQL, Docker Compose и дашборд относятся к следующим шагам.

## Запрос

https://api.unhcr.org/population/v1/population/?yearFrom=2021&yearTo=2025&coo=UKR&coa=DEU&cf_type=ISO&limit=100

- yearFrom/yearTo — границы периода включительно.
- coo — страна происхождения; coa — страна убежища/проживания.
- cf_type=ISO — фильтруем по ISO3, поэтому Германия — DEU.
- limit — размер страницы. Для полной выгрузки нужно пройти page=1…maxPages.
- Без фильтра по стране соответствующее измерение агрегируется; для детализации
  всех стран служат coo_all=true и coa_all=true.

## Поля

| Поле | Значение |
|---|---|
| year | Отчётный год; основные показатели численности относятся к концу года |
| coo_name / coa_name | Название страны происхождения / убежища или проживания |
| coo_iso / coa_iso | Коды ISO3 |
| coo / coa | Коды UNHCR: могут отличаться от ISO3 |
| coo_id / coa_id | Внутренние идентификаторы UNHCR |
| refugees | Беженцы под мандатом UNHCR, включая людей в ситуации, подобной положению беженцев |
| asylum_seekers | Ищущие убежища, ожидающие решения; не количество новых заявлений за год |
| idps | Внутренне перемещённые лица в охвате статистики UNHCR; не все ВПЛ мира |
| oip | Другие люди, нуждающиеся в международной защите |
| stateless | Люди в рамках мандата UNHCR по безгражданству |
| ooc | Другие лица, представляющие интерес для UNHCR |
| hst | Принимающие сообщества, которым оказывает помощь UNHCR |
| returned_refugees | Беженцы, вернувшиеся за отчётный год: поток, не численность на конец года |
| returned_idps | ВПЛ, вернувшиеся за отчётный год: поток |
| items | Массив записей ответа |
| page / maxPages | Текущая страница / число страниц |
| short-url | Служебный идентификатор короткой ссылки |
| total | В проверенных ответах пустой массив; не используем как число строк |

## Что проверено, а что ещё нет

На 7 октября 2026 API доступен без ключа; получены HTTP 200.
Наличие пяти годовых итогов и 15 пар год–страна проверяется автоматически,
как и отсутствие повторов ключа год–страна происхождения–страна убежища.
Наличие итогов НЕ доказывает полноту всех стран и категорий.
Для следующего шага: полная детализация с пагинацией, справочник стран,
сноски /footnotes/, профиль пропусков, сверка сумм с мировыми итогами.
Не следует строить ожидаемые строки как все мыслимые пары стран: отсутствие
строки не обязательно означает ошибку или нулевую численность.
Справочник /years/ при первичной проверке содержал даже 2026 и 2027:
он сам по себе не подтверждает наличие завершённых годовых данных.

## Методологические ограничения

1. Не складываем годовые остатки: один человек может входить в несколько лет.
2. Разница численности между годами — не число новых перемещений.
3. Не суммируем все поля: здесь смешаны остатки, возвраты за год и принимающее население;
   возможны пересечения статусов, в частности с безгражданством.
4. refugees не включает отдельный массив палестинских беженцев под мандатом UNRWA.
   Это не общее число всех вынужденно перемещённых в мире.
5. В числовых полях встречаются числа, строки '0' и '-'. Исходный ответ сохраняем.
   '-' пока считаем специальным отсутствующим/неприменимым значением, а не нулём;
   точное значение для конкретной записи уточняем по сноскам.
   В географических полях '-' в наших агрегированных запросах означает свёрнутое измерение.
6. Категория oip введена в 2022 году; сопоставимость с данными 2021 требует оговорки
   о ранее отдельно учитывавшихся венесуэльцах, перемещённых за границу.
7. Исторические данные пересматриваются. Фиксируем дату загрузки и исходный ответ.
